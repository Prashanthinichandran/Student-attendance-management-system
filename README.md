# Student Attendance Management System

 Project Description
The Student Attendance Management System is a simple web-based project developed to manage and track student attendance efficiently.

 Features
* Add student details
* Mark student attendance
* View attendance records
* Calculate attendance percentage
* Simple and user-friendly interface

Technologies Used
* HTML
* CSS
* JavaScript

 Project Files
* `index.html` – Main webpage
* `style.css` – Styling and layout
* `script.js` – Project functionality

 How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the application to manage student attendance.

Project Type
BCA Mini Project
